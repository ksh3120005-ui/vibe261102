KOSPI200 · 거래대금 상위 크롤러  v1.0.0
==========================================

네이버페이 증권(https://stock.naver.com)의 코스피200 지수, 일별 시세,
거래대금 상위 종목을 모아 보여주고 CSV / 엑셀 파일로 저장하는 프로그램입니다.


■ 실행 방법
  1. 압축을 풀고 Kospi200Crawler.exe 를 더블클릭합니다. (설치 필요 없음, 인터넷 연결 필요)
  2. 시장(전체/코스피/코스닥), 종목 수, 일별 시세 일수를 고르고 [수집 시작]을 누릅니다.
  3. [CSV 저장]은 보고 있는 탭을, [엑셀 저장]은 두 탭을 시트별로 한 파일에 저장합니다.
  4. 종목을 더블클릭하면 네이버 종목 페이지가 열립니다. 표 머리글을 누르면 정렬됩니다.


■ "Windows의 PC 보호" 창이 뜨는 경우
  코드 서명이 없는 프로그램이라 처음 실행할 때 SmartScreen 경고가 나올 수 있습니다.
  [추가 정보] → [실행]을 누르면 됩니다.


■ 참고
  - 처음 실행할 때는 압축을 푸느라 몇 초 걸릴 수 있습니다.
  - 네이버 내부 API를 사용하므로 네이버가 구조를 바꾸면 동작하지 않을 수 있습니다.
  - 수집한 데이터는 개인적인 참고용으로만 사용하세요. 투자 판단의 근거로 삼지 마세요.
  - Windows 10 / 11 (64비트)에서 동작합니다.
