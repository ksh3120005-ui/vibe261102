S&P 500 Analytics · 과거 데이터 분석기  v1.0.0
=============================================

S&P 500 과거 데이터 CSV 를 불러와 데이터 클렌징, 다각도 분석, 차트 시각화를 하고
결과를 PNG / CSV / 엑셀(xlsx) 파일로 저장하는 프로그램입니다.


■ 실행 방법
  1. 압축을 풀고 SP500Analytics.exe 를 더블클릭합니다. (설치 필요 없음)
  2. [찾아보기]로 "S&P 500 과거 데이터.csv" 파일을 선택하면 바로 분석합니다.
     ※ CSV 파일을 exe 와 같은 폴더에 두면 실행할 때 자동으로 불러옵니다.
  3. [차트] 탭에서 차트 종류를 고르고, 종가 라인그래프는 기간을 바꿀 수 있습니다.
  4. [엑셀로 저장]은 요약 · 정제 데이터 · 연도별 분석 · 월별 수익률 · 차트 시트를
     한 파일에 저장합니다. 기본 저장 위치는 exe 옆의 output 폴더입니다.


■ CSV 형식
  Investing.com 한국어 "과거 데이터" 다운로드 형식
  (열: 날짜, 종가, 시가, 고가, 저가, 거래량, 변동 %)


■ "Windows의 PC 보호" 창이 뜨는 경우
  코드 서명이 없는 프로그램이라 처음 실행할 때 SmartScreen 경고가 나올 수 있습니다.
  [추가 정보] → [실행]을 누르면 됩니다.


■ 참고
  - 처음 실행할 때는 압축을 푸느라 몇 초 걸릴 수 있습니다.
  - 분석 결과는 학습·참고용입니다. 투자 판단의 근거로 삼지 마세요.
  - Windows 10 / 11 (64비트)에서 동작합니다.
